# Evidence Design

Use evidence for a job:

- quantitative scale establishes magnitude;
- standard/rule establishes what is required or permitted;
- case instantiates a mechanism;
- demonstration shows a transformation;
- counterexample tests a boundary.

For a central claim, combine independent modes when practical. Check source authority, date, scope, units, denominator, and whether the source supports causation or only correlation. A vivid case is not a substitute for a general claim; a number is not a substitute for explanation.
