# Narrative Structures

Choose the smallest structure that can answer the question:

1. Process: outcome → stages → checks → failure/quality → synthesis.
2. Mechanism: familiar result → minimum model → worked example → real constraints → synthesis.
3. Investigation: anomaly → competing explanations → evidence → ruling out → best explanation → limits.
4. Decision/risk: ordinary choice → hidden incentives/constraints → mechanism → safer interpretation/action → limits.

For every block specify `function`, `input`, `new_information`, `output`, `relation_in`, and `relation_out`. Remove blocks that do not change the viewer's model or prepare a necessary dependency.
