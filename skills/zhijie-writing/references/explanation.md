# Explanation Techniques

Use this sequence for a new technical concept:

`name object → give its job → show one relation → ground with example/scale → restore exceptions`

Use analogy only for the preserved relationship and state where it stops. Use minimum models for mechanisms, worked examples for algorithms/formulas, scale conversion for large quantities, and progressive disclosure for standards or taxonomies. Return to the real system after simplifying; do not let the model become a false universal.
