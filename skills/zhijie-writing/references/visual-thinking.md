# Visual Thinking

For every dense claim, specify:

```text
Visual target:
Visual operation: structure / process / scale / decode / compare
Narration dependency:
Viewer takeaway:
Evidence boundary:
```

Use diagrams for relationships, animation for transformations, scale graphics for quantities, annotated examples for decoding, and side-by-side comparisons for trade-offs. A visual must clarify the argument, not merely repeat nouns or imply unsupported evidence.
