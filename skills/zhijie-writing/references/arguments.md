# Argument Mapping

Use one row per major claim:

| Claim | Evidence | Explanation | Inference | Consequence | Confidence | Gap/repair |
|---|---|---|---|---|---|---|

Evidence establishes; explanation connects; inference extends; consequence answers “so what?”. If evidence does not entail the claim, weaken the claim, add a bridge, or remove it. Introduce counterarguments only when a reasonable viewer would predict a different result. Mark uncertainty explicitly.
