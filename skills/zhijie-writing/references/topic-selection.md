# Topic Selection

## Decision rule

Keep a topic when it has a visible outcome, a hidden dependency, and a bounded answer. Narrow broad themes to one mechanism, decision, failure, or transformation.

## Deliverable

```text
Audience/K0:
Visible outcome:
Common assumption:
Hidden dependency:
Core question:
Scope boundary:
Why this evidence can answer it:
```

Use this thesis: `People observe X and assume Y; this video shows how Z produces X under condition C.` Reject a topic whose only value is novelty or whose evidence cannot resolve the question.
